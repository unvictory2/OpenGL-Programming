### 프로젝트 세팅 유지하며 사용하기
1. `main.c` 수정
2. 다른 이름으로 저장, ex)`01_Hello_Window`
3. 다른 코드 작업할 때 다시 `main.c` 수정
4. `main.c`말고 다른 이름으로 저장된 애는 VS에서 불러오지 말 것 > `main`함수 여러 개라 충돌 발생
